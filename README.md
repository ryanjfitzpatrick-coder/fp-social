# fp-social

Public images for First Pull Sports Cards' Instagram posts. Metricool downloads each image
from its link here when it publishes a post.

Link format:
https://raw.githubusercontent.com/ryanjfitzpatrick-coder/fp-social/main/posts/<file>.jpg

Rules: this repository is PUBLIC. Only finished post images that are meant to go on
Instagram go here. Never rosters, player names lists, original photos, or any photo
of a kid that isn't approved for social media. Don't delete images that are used by a
post still waiting in Metricool.
